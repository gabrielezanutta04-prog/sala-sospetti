# Istruzioni per Claude Code

Progetto: prototipo front-end di un gioco stile Among Us a soli pulsanti. Leggi `README.md`
per schermate, regole già decise e struttura del codice.

- Lingua dell'interfaccia e dei commenti: italiano.
- Un solo file `index.html` (HTML + CSS + JS inline), nessuna build, nessuna dipendenza
  oltre ai Google Fonts. Mantieni questa struttura finché non si introduce un backend.
- Non cambiare le regole di gioco elencate nel README senza che vengano chieste.
- Il pannello "Simulatore" è solo per il prototipo: quando si aggiunge un backend reale va rimosso.
- Le schermate di civili e assassini devono restare identiche a meno che l'assassino
  non abbia reso visibile il riquadro Uccidi con la pressione lunga.
- Prima di consegnare: `node --check` sullo script estratto, prova a 400 px di larghezza.
